# 笔记审阅提示词

写完后在这个聊天中粘贴以下内容，可以把“本次改动”替换为具体文件路径。

> 请根据 writing/STYLE_GUIDE.md 审阅我本次新增或修改的笔记。
>
> 先阅读原文和差异，再把意见分成“格式问题、表达建议、技术疑问”。每项注明文件与位置，说明原因，必要时给出修改前后对照。
>
> 只处理笔记，不修改网站功能。技术结论、公式、代码、数值、单位和寄存器含义默认保留；发现疑点时列出待核实的问题与依据，不要直接更正。需要技术核实时优先使用官方协议、数据手册或原始论文，并标明资料版本。
>
> 检查标题和正文是否一致、适用范围是否明确、术语是否解释、事实与推测是否区分、步骤是否完整、图片说明是否清楚、重复内容是否可以合并。
>
> 首先给出审阅报告。只有我明确要求应用修改时，才改写原文；应用后比较代码和公式、检查旧链接，并执行排版检查和生产构建。

自动格式检查与这份 AI 审阅是两回事。GitHub Actions 只运行确定性的格式检查，不会替你确认技术准确性；使用本提示词不需要新增 AI API 服务。
