# 1. DML：直接调制激光器

DML通过直接改变激光器注入电流，使激光器输出功率随数据变化：

```
驱动电流变化
    ↓
激光器载流子数量变化
    ↓
受激辐射强度变化
    ↓
输出光功率变化
```

也就是说：

> DML既负责产生光，又负责调制光。

## 工作原理

当Driver提供PAM4电流时：

```
电流Level 0 → 较低光功率
电流Level 1 → 次低光功率
电流Level 2 → 次高光功率
电流Level 3 → 较高光功率
```

因此一颗DML可以直接输出PAM4光信号。

##  DML关光方式

DML关光通常通过：

- 降低或关闭激光器Bias Current；
- 关闭Laser Driver；
- 将电流降到阈值以下。

注意：

```
激光器Bias Current < 阈值电流
→ 不再正常产生激光
```

DML没有MZM的Null工作点。



# 2.EML：电吸收调制激光器

典型结构：

```
DFB Laser → EAM → 输出光
```

其中：

- DFB Laser持续产生连续光；
- EAM负责控制光吸收多少；
- 两者通常集成在同一颗InP芯片上。

电链路：

```
DSP
 ↓
EML Driver
 ↓
EAM调制电压
 ↓
改变EAM吸收率
 ↓
输出光功率变化
```

EML不是直接调制激光器电流，而是：

> 激光器持续发光，后面的EAM像一个高速可控“光闸门”。

## 工作原理

**EML由DFB和EAM组成**

```
DFB Laser → EAM → 光纤
```

DFB Laser输出连续光，EAM通过电压控制材料吸收系数。

当EAM吸收小：

```
更多光通过 → 高光功率
```

当EAM吸收大：

```
更多光被吸收 → 低光功率
```

##  EML关光方式

可以通过：

- 将EAM调到高吸收状态；
- 关闭DFB Laser；
- 同时关闭Driver和Laser。

所以EML也存在两种“关”：

```
EAM高吸收：
激光器仍在发光，但输出被吸收

Laser关闭：
光源本身停止输出
```



# 3. 硅光MZM方案

典型结构：

```
CW Laser → Silicon Photonics PIC → MZM → 输出光
```

电链路：

```
DSP
 ↓
MZM Driver
 ↓
RF高速信号
 ↓
硅光PN相移器改变光相位
 ↓
MZM干涉
 ↓
输出光功率变化
```

硅光MZM本身通常不产生光，而是调制外部CW激光器提供的连续光。

也就是：

> 激光器负责产生光，硅光MZM负责通过相位变化和干涉调制光.
