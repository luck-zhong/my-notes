# 一、光纤连接器

## MPO

800G 2xDR4：指2个“400G-DR4”接口。它配有2个MPO-12连接器，无需光纤分支线缆，每个800G光模块可实现2个物理上不同的400G-DR4链路。（MPO连接器：MPO-12【中间4根光纤没用】）

**注：当左右对接时，关闭Tx1，实际是Rx5没光。**

# 二、光模块中的速率：Gbps、Gbaud 与 DSP 配置速率

## 1. 需要区分的三个速率

在光模块和 DSP 配置中，经常会同时看到 **25G、50G、53.125 Gb/s、26.5625 GBd** 等数字。

它们表示的并不是同一个概念，需要区分：

| 名称                 | 示例                       | 含义                                                     |
| -------------------- | -------------------------- | -------------------------------------------------------- |
| 标称速率             | 25G、50G                   | 平时描述一个 Lane 能承载多大业务带宽时使用               |
| 线路比特率 Line Rate | 25.78125 Gb/s、53.125 Gb/s | PHY 实际在线路上传输的 bit rate                          |
| 符号率 Baud Rate     | 25.78125 GBd、26.5625 GBd  | 每秒发送多少个 Symbol，DSP/SerDes 常使用这个速率进行配置 |

因此：

> 平时所说的“50G Lane”并不意味着 DSP 一定配置成 50 GBd。

------

## 2. Gbps 与 Gbaud 的区别

### Gbps

**Gbps（Gigabit per second）表示比特率。**

即：

> 每秒传输多少个 bit。

例如：

```text
53.125 Gb/s
```

表示每秒传输：

```text
53.125 × 10^9 bit
```

------

### Gbaud

**Gbaud 表示符号率 Symbol Rate。**

即：

> 每秒传输多少个 Symbol。

一个 Symbol 能携带多少 bit，由调制方式决定。

------

## 3. NRZ 与 PAM4 的区别

### NRZ

NRZ 只有两个电平：

```text
Low
High
```

因此一个 Symbol 只能表示两种状态：

```text
0
1
```

所以：

```text
1 Symbol = 1 bit
```

因此对于 NRZ：

```text
Bit Rate ≈ Baud Rate
```

例如典型 25G NRZ：

```text
Line Rate = 25.78125 Gb/s

因为：
1 Symbol = 1 bit

所以：

Baud Rate = 25.78125 GBd
```

------

### PAM4

PAM4 有四个电平，可以表示四种状态，例如：

```text
00
01
11
10
```

因此：

```text
1 Symbol = 2 bit
```

所以 PAM4 中：

```text
Bit Rate = 2 × Baud Rate
```

------

## 4. 为什么 50G PAM4 的 DSP 配置是 26.5625 GBd？

平时所说的：

```text
50G Lane
```

是标称的数据速率。

由于 Ethernet PCS / FEC 等机制存在编码和冗余开销，物理线路实际运行的速率会更高。

典型 50G PAM4 Lane 的线路速率为：

```text
53.125 Gb/s
```

由于 PAM4：

```text
1 Symbol = 2 bit
```

所以：

```text
Symbol Rate
= 53.125 Gb/s ÷ 2 bit/Symbol
= 26.5625 GSymbol/s
= 26.5625 GBd
```

DSP 中看到的：

```text
26562.5 MBd
```

就是：

```text
26.5625 GBd
```

因此整个关系是：

```text
标称速率
50G
 │
 │ PCS / FEC 等开销
 ↓
实际线路比特率
53.125 Gb/s
 │
 │ PAM4：2 bit / Symbol
 ↓
符号率
26.5625 GBd
 │
 ↓
DSP配置
26562.5 MBd
```

------

## 5. 为什么 25G 和 50G 的 Baud Rate 差不多？

这是 NRZ → PAM4 的一个关键区别。

### 25G NRZ

```text
25G NRZ
   │
   ↓
约 25.78125 Gb/s
   │
   │ 1 bit / Symbol
   ↓
约 25.78125 GBd
```

### 50G PAM4

```text
50G PAM4
   │
   ↓
53.125 Gb/s
   │
   │ 2 bit / Symbol
   ↓
26.5625 GBd
```

可以对比：

| 类型     | Line Rate        | 每 Symbol bit 数 | Baud Rate       |
| -------- | ---------------- | ---------------- | --------------- |
| 25G NRZ  | 约 25.78125 Gb/s | 1                | 约 25.78125 GBd |
| 50G PAM4 | 53.125 Gb/s      | 2                | 26.5625 GBd     |

可以看到：

```text
25G NRZ：约 25.8 GBd
50G PAM4：约 26.6 GBd
```

两者的 Baud Rate 很接近。

但是 PAM4 一个 Symbol 可以携带 2 bit，因此在 Baud Rate 几乎不变的情况下，可以实现约两倍的数据传输速率。

------

## 7. 核心理解

记住下面三个关系：

```text
标称速率
    ≠
Line Rate
    ≠
Baud Rate
```

以及：

```text
NRZ：
1 Symbol = 1 bit

PAM4：
1 Symbol = 2 bit
```

因此：

```text
NRZ：
Bit Rate ≈ Baud Rate

PAM4：
Bit Rate ≈ 2 × Baud Rate
```

对于典型 50G PAM4：

```text
50G（标称）
        ↓
53.125 Gb/s（Line Rate）
        ↓
26.5625 GBd（Symbol Rate）
        ↓
26562.5 MBd（DSP配置值）
```

# 三、OSFP-IHS  和OSFP-RHS

在光模块机械结构里，**OSFP-IHS** 和 **OSFP-RHS** 通常指 OSFP 模块的两种散热器方案：

- **IHS = Integrated Heat Sink，集成式散热器**
- **RHS = Riding Heat Sink，骑乘式/外置压接散热器**

核心区别是：**散热器是在模块上，还是在笼子（cage）上。**

### OSFP-IHS

OSFP-IHS 的散热器直接集成在模块外壳顶部，模块本身带明显的散热鳍片。

可以粗略理解成：

```
      散热鳍片
    |||||||||||
   ┌───────────┐
   │   OSFP    │
   │  Module   │
   └───────────┘
```

因此散热路径大致是：

```
DSP / Driver / 光器件
        ↓
模块壳体
        ↓
模块自带 Heat Sink
        ↓
机箱风流
```

这种结构常见于高功耗 OSFP，例如 **800G、1.6T** 等，因为模块可以针对自己的功耗和热点专门设计散热器。

### OSFP-RHS

RHS 中，模块顶部通常相对平整，**散热器属于 Cage / Connector Assembly，而不是模块本身**。

模块插入 Cage 后，上面的散热器通过弹簧压力压在模块顶面：

```
       Cage Heat Sink
      |||||||||||||||
      ───────────────
           ↓ 压紧
   ┌───────────────┐
   │  OSFP Module  │
   └───────────────┘
```

散热路径是：

```
DSP / Driver / 光器件
        ↓
模块上壳
        ↓
TIM / 接触面
        ↓
Cage 上的 Riding Heat Sink
        ↓
机箱风流
```

之所以叫 **Riding Heat Sink**，可以理解为散热器“骑”在模块顶部。

### 两者放在一起看

| 项目         | OSFP-IHS             | OSFP-RHS             |
| ------------ | -------------------- | -------------------- |
| 全称         | Integrated Heat Sink | Riding Heat Sink     |
| 散热器属于谁 | 模块                 | Cage / 主机          |
| 模块顶部     | 自带散热鳍片         | 通常较平             |
| 插拔模块时   | 散热器一起拔出来     | 散热器留在设备里     |
| 散热设计责任 | 更偏模块厂           | 更依赖系统厂         |
| Cage 结构    | 相对简单             | 需要压紧散热机构     |
| 高功耗适应性 | 通常较好             | 强依赖 Cage/风道设计 |

# 四、PAM4

**PAM4 =  **MSB（高权重 NRZ） + LSB（低权重 NRZ） → 4 个光功率等级**

上路：**MSB**（蓝色）

- 只有 2 个电平
- 光功率：`0 mW / 4 mW`

下路：**LSB**（黄色）

- 先被 **÷2（幅度缩小一半）**
- 光功率：`0 mW / 2 mW`

中间那个 **“+”**：

- 是**模拟电流 / 光功率叠加**
